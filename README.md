# apexType ⌨️

**Entrenador de mecanografía premium** para desarrolladores y amantes de la escritura. Practica código real y textos en español e inglés con estadísticas en tiempo real.

## ✨ Características

- **💻 Modo Programación** — fragmentos reales en JavaScript, Python, PHP, Go, Java y CSS
- **✍️ Modo Lectura y Escritura** — citas literarias, historias cortas y curiosidades en Español e Inglés
- **📊 Estadísticas en tiempo real** — WPM y Precisión calculados mientras escribes
- **🏆 Sistema de XP y Niveles** — sube de nivel a medida que practicas, guardado en `localStorage`
- **🎨 Diseño glassmorphism cyberpunk** — paleta neón cian + violeta, animaciones suaves
- **⌨️ Atajos de teclado** — `Tab` para reiniciar, detección de Bloq Mayús

## 🚀 Cómo ejecutar localmente

```bash
# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm run dev
```

El servidor se levanta en `http://localhost:5173`

## 🛠️ Tecnologías

| Tecnología | Uso |
|---|---|
| Vanilla JS (ES Modules) | Lógica principal |
| Vite 8 | Bundler / Dev Server |
| JetBrains Mono | Fuente monoespaciada para código |
| Outfit | Fuente principal UI |
| CSS Custom Properties | Sistema de diseño |
